## 项目初始化

当你创建一个空的项目时，以下是你要进行的操作：

- 创建独立的项目文件夹（如需要）
- 创建 Git 仓库，并填写确认远程地址
- 确认 Git commit 的用户名、邮箱、GPG Key 等信息是否存在、是否正确
- 创建以下文件
    - `.gitignore`
    - `.gitattributes`
    - `.editorconfig`
    - `AGENTS.md`
    - `README.md` （内部填写项目名）
- 以 `meta: 初始化项目` 做第一次 commit
